Live Metrics
Signal Metrics
RSRP
--
Reference Signal Received Power. Measures LTE signal strength. Closer to 0 is stronger; for example, -77 dBm is generally good.
RSRQ
--
Reference Signal Received Quality. Indicates signal quality and congestion/interference. Less negative is better.
SINR
--
Signal-to-Interference-plus-Noise Ratio. Higher is better. This is one of the best indicators of usable radio quality.
RSSI
--
Received Signal Strength Indicator. Total received power, including signal, interference, and noise. Useful, but less precise than RSRP/SINR.

Tower Info
eNodeB ID
--
LTE base station identifier. Helps identify the tower or site serving your router.
Band / CA
--
Shows LTE band and carrier aggregation details. Example: B1 + B3 + B8 means the router is using multiple LTE carriers together.
EARFCN
--
E-UTRA Absolute Radio Frequency Channel Number. Identifies the LTE downlink/uplink frequency channels.
DL / UL Bandwidth
-- / --
Downlink and uplink LTE channel bandwidth. Higher bandwidth usually allows higher throughput if radio quality is good.
TAC
--
Tracking Area Code. Used by the mobile network to group cells for mobility and paging.
PLMN
--
Public Land Mobile Network code. Identifies the country and operator. For example, Egypt MCC is 602.
Transmission Mode
--
LTE transmission mode. Indicates the MIMO/transmission scheme used by the LTE radio link.
CQI
--
Channel Quality Indicator. Higher CQI generally means the router can use more efficient modulation and coding for better throughput.
